# PATCH.WAD - loaded after BASE.WAD, and holding something for every finding
# wadinfo makes.
#
#   npm run wad -- build projects/programs/apps/wadinfo/fixture/patch.txt projects/programs/apps/wadinfo/PATCH.WAD

# Shadows the base's HELLO.
lump HELLO text hello2.txt

# Types a foreign lump the base left untyped.
row RAWDATA raw

# The base's MAP01 has a header, and a header wins: this row is a disagreement.
row MAP01 text

# Names a lump no file has.
row GHOST palette

# Three bytes nothing references, an entry inside HELLO, and one past the end
# of the file - a directory is free-form, and these are what a checker is for.
pad 3
entry ECHO 12 8
entry LOST 4000 10

# One payload under four names: an alias set, which is structure rather than
# damage. DSSILENT lands at 39, past HELLO's 24 bytes at 12 and the pad, and is
# 13 bytes - its header and the 9 of silence.txt - so the entries say 39 13.
lump DSSILENT raw silence.txt
entry DSNOWAY 39 13
entry DSBGACT 39 13
entry DSPOSIT1 39 13

# Someone else's bytes that happen to start 'M' 'o' 'A' - and 'A', 65, is no
# type a header carries, so this is not a header and the row is its type.
foreign NOISE noise.txt
row NOISE raw
